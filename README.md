# Ravi Sharma — Portfolio Site

A small multi-page portfolio website for Ravi Sharma, a brand and product designer.

## Pages
- `index.html` — Home: intro, featured work, services
- `work.html` — Work: filterable project grid
- `about.html` — About: bio, skills, experience timeline
- `contact.html` — Contact: validated contact form and contact details

## Structure
```
.
├── index.html
├── work.html
├── about.html
├── contact.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── README.md
```

## Tech
Plain HTML, CSS, and vanilla JavaScript — no build step required. Fonts are loaded from Google Fonts via CDN.

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static file server.

## Live site
Deployed via GitHub Pages from the `main` branch root.
